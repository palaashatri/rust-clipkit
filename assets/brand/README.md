# ClipKit visual identity

Polished translucent coral media-card/play icon proposal, aligned to Loom's tactile rounded-square materials. Includes original transparent source crop, resampled 16–1024px PNGs, ICO, ICNS, wordmark and 1200×630 social preview. Replaces rejected flat line SVGs. Large image sizes are resampled from a ~248px generated contact-sheet crop rather than native high-resolution masters. Draft only; please check 16px legibility and actual packaging integration before merge.
